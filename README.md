# Bread Family Bakery Landing Page

A modern, responsive landing page for a bakery built with Next.js 14 and Tailwind CSS.

## Tech Stack

- [Next.js](https://nextjs.org/) - React framework
- [Tailwind CSS](https://tailwindcss.com/) - For styling
- [Framer Motion](https://www.framer.com/motion/) - Animations
- [React Hook Form](https://react-hook-form.com/) - Form handling
- [Google Maps API](https://developers.google.com/maps) - Maps integration
- [Lottie React](https://lottiereact.com/) - Loading animations

## Features

- 🎨 **Modern Design** - Clean and responsive UI built with Tailwind CSS
- 🌊 **Smooth Animations** - Engaging page transitions and scroll animations using Framer Motion  
- 📱 **Fully Responsive** - Works seamlessly on desktop, tablet, and mobile devices
- 🗺️ **Google Maps Integration** - Interactive store location map
- 📊 **Dynamic Counters** - Animated statistics and numbers
- 🖼️ **Gallery Section** - Showcase of bakery products and ambiance
- 📝 **Contact Form** - Integrated contact form with validation
- ⚡ **Fast Performance** - Built on Next.js for optimal loading speeds
- 🎯 **SEO Optimized** - Includes metadata and semantic HTML for better search visibility

## Getting Started

To clone and run this application, you'll need [Git](https://git-scm.com/) and [Bun](https://bun.sh/) installed on your computer. From your command line:

```bash
# Clone this repository
$ git clone https://github.com/ixedasan/bakery-landing-page.git

# Navigate to the project directory
$ cd bakery-landing-page

# Install dependencies
$ bun install

# Set up environment variables
$ cp .env.example .env

# Start the development server
$ bun dev
```
